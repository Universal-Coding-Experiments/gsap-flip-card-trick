# ✨ GSAP Flip Card Slider: Interactive UI Design

[![Vanilla JS](https://img.shields.io/badge/Logic-Vanilla--JS-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

A dynamic and interactive card slider built using the **GSAP Flip Plugin**, **Bootstrap 5**, and **Vanilla JavaScript**. Each click triggers a smooth, cinematic flip animation where the last card seamlessly moves to the front, creating a layered depth effect.

## 🚀 Key Features

- **GSAP Flip Plugin**: Enables complex state transitions with minimal code, ensuring ultra-smooth card movements.
- **Dynamic Layering**: CSS positioning creates a stacked, offset appearance for a premium visual feel.
- **Smart DOM Management**: Efficiently handles card reordering to maintain a continuous, infinite-like sliding experience.
- **Interactive Triggers**: Global click events choreographed with GSAP's timeline for responsive, tactile feedback.
- **Bootstrap 5 Integration**: Leverages modern layout utilities for a responsive and clean foundation.
- **Beginner-Friendly Architecture**: A perfect starting point for learning GSAP-based UI animations.

---

## 🛠️ Tech Stack

### Frontend & Animation
- **GSAP (GreenSock)**: Specifically the `Flip` plugin for high-performance layout transitions.
- **Bootstrap 5**: CSS framework for structure and responsive styling.
- **Modern CSS**: Custom transformations and z-index layering for the "stacked" effect.
- **Vanilla JavaScript**: Lightweight DOM manipulation and event handling logic.

---

## 🌓 Design Philosophy

This project focuses on **Seamless Layout Transitions**. Using the "FLIP" (First, Last, Invert, Play) technique, we bridge the gap between static CSS layouts and fluid interactive motion. The goal is to make structural changes to the DOM feel like organic animations, providing a polished and engaging user experience.
